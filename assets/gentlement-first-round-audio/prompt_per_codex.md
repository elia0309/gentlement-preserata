# Prompt da inviare a Codex

Parti da questa richiesta dell'utente e trasformala in modifiche concrete al progetto.

## Contesto
L'utente ha inviato un breve audio (`AUDIO-2026-06-10-14-19-13(1).m4a`).

## Richiesta
Trascrivi o interpreta il contenuto dell'audio e poi applica la richiesta al codice del progetto.

## Istruzioni per Codex
1. Ispeziona la struttura del progetto prima di modificare file.
2. Individua i file rilevanti.
3. Implementa la modifica richiesta dall'audio nel modo più semplice e pulito possibile.
4. Mantieni lo stile esistente del codice.
5. Esegui test, lint o build disponibili nel progetto.
6. Alla fine, riassumi:
   - file modificati;
   - cosa è stato cambiato;
   - eventuali comandi eseguiti;
   - eventuali dubbi o passaggi manuali rimasti.

## Nota
Se l'audio non è direttamente accessibile o non è trascrivibile, chiedi all'utente una trascrizione testuale prima di modificare il codice.
